# KakuPoly — iPad 向け PS1風ポリゴンエディタ

カクカクのローポリモデルを、モデリング → ドット絵テクスチャ → ボーン → アニメ → 書き出し まで iPad 1台で作るためのエディタです。
Apple Pencil を主な入力にし、TourBox Elite Plus（iPad では Bluetooth キーボードとして動作）にもショートカットを割り当てられます。

## できること

| モード | 主な機能 |
|---|---|
| モデリング | 頂点/辺/面の選択（タップ・範囲）、押し出し、インセット、ループカット、細分化、辺の分割、2頂点を結ぶ、面を張る、結合・溶接、辺の溶解、複製、Xミラー、X対称編集、三角形化、分離、グリッド吸着、頂点カラー塗り |
| テクスチャ | 1ピクセル単位のペン・消しゴム・塗りつぶし・スポイト・直線・矩形、**3Dモデル上に直接描く**、UV展開（画面/箱/軸）、UVの網目をピクセル吸着で編集、写真を「PS1風」に変換して取り込み（縮小＋減色＋4×4ディザ＋15bit化） |
| リグ | モデルをタップして体の中心にジョイントを置く、親子の付け替え、左右対称に複製（.L/.R）、自動ウェイト（1頂点＝1ボーン）、手動割り当て、ウェイト色表示 |
| アニメ | ボーンを回す/動かす/拡縮すると自動でキー、タイムライン（◆をドラッグでキー移動）、直線補間/ステップ補間、ポーズのコピー・左右反転貼り付け、再生 |
| 入出力 | 端末内への自動保存、.kpoly（独自形式）、**読み込み: glTF/GLB・OBJ(+MTL)・FBX**（三角形を四角形にまとめ直す）、**書き出し: GLB（骨・アニメ込み）**・OBJ・PNG |

PS1表示（上部「表示」）: 低解像度描画、頂点のピクセル吸着（ガタつき）、遠近補正なしのテクスチャ（ゆがみ）、15bitカラー＋4×4ディザ。

## 入力

- Apple Pencil / マウス左: 選択・ギズモ操作・描画（ホバーで描画位置を表示、240Hz の筆跡を取りこぼさないよう合体イベントを使用）
- 指: 1本で視点回転、2本でズームと移動、2本タップで取り消し、3本タップでやり直し（ペン使用中の指は無視）
- 右上の ⟲ ✥ ⊕ ボタン: ペンだけで視点操作
- ボタンの長押し（マウスは右クリック）: そのボタンの説明を表示。上部の「?」に作業の手順
- キー: 右上の ⌨ から一覧・変更。「＋キー」を押して TourBox を操作すると、その入力を覚えます

## 開発

```sh
npm install
npm run dev          # 開発サーバ（--host 付き。同じLANの iPad から http://<PCのIP>:5173 で開ける）
npm test             # 単体テスト（メッシュ編集・骨格・PNG・GLBの公式Validator検証・読み戻し）
npm run build        # dist/ に書き出し（静的ファイル。https で配信すればホーム画面に追加できる）
npm run build:single # dist-single/index.html に1ファイルで書き出し
node scripts/make-icons.mjs  # アイコン再生成
```

構成: `src/core`（three.js 非依存のデータと編集処理）、`src/view`（描画・入力・ギズモ）、`src/ui`（画面）、`src/io`（保存・glTF/OBJ/FBX）、`src/input`（キー割り当て）。
